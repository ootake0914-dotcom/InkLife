# InkLife 3D Companion Station 🐾
**ESP32-S3 E-Ink サイバー生命体「InkLife」のためのネイティブ 3D デスクトップ観測ステーション**

Raylib 6.0 (C言語ネイティブ高速 3D エンジン) + Python による本格的なデスクトップ・コンパニオンアプリです。
ブラウザ版のチープな板レリーフを廃止し、**フルカラー 3D ボクセル (Voxel) キメラ、足元の Brian's Brain 現象盤ホログラム、実機 296x128 E-Ink 完全再現ディスプレイ、LoRa 知人帳レーダー** を備えたリッチな観測ステーションとして生まれ変わりました。

## 🎮 主な機能・操作方法

### 1. 3D Voxel テラリウム空間 (画面左側)
- **フルカラー立体ボクセル**:
  - キメラのドット絵を立体キューブ化。ドラゴンの角、柴犬の耳、背中トゲ、星屑オーラが部位別に色分けマウントされます。
- **呼吸 & 感情モーション**:
  - ぷにぷにとした呼吸（スカッシュ＆ストレッチ）。
  - HAPPYでピョンピョン跳ね、SLEEPYで丸まって「Zzz」を浮かべ、SICKでブルブル震えます。
- **マウス操作**:
  - **左ボタンドラッグ**: カメラを 360 度グリグリ回転。
  - **マウスホイール**: ズームイン／ズームアウト。
  - **キメラをクリック**: 「なでなで」ふれあいリアクション（ピョンと跳ねてご機嫌UP）。

### 2. 足元の Brian's Brain 現象盤ホログラム
- Core 0 で計算されている 48x12 のセル・オートマトン生命現象盤が、テラリウム台座の上で 3D 発光キューブとしてリアルタイムに脈動します。

### 3. 実機完全同期 バーチャル E-Ink ディスプレイ (画面右上)
- 実機（296x128）の画面を 2 倍スケール（592x256）でピクセル完全再現。
- 標本窓・キメラアート・ステータスバー・現象盤ミニ窓・イベントログが実機と 100% 同期して動きます。

### 4. LoRa メッシュ知人帳レーダー (画面右中段)
- LoRa すれ違い通信で出会った他のキメラたちの DID、好感度ゲージ（-100〜+100）、電波強度（RSSI）、関係（親友／ライバル）をカード形式で表示。

### 5. ラボコントロール & コマンド (画面右下)
- **FEED**: キメラにご飯をあげて満腹度を回復。
- **PLAY**: 一緒に遊んでエネルギーを消費し、幸福度を大幅回復。
- **SYNC TIME**: PC の現在時刻（Unix time）を実機へ即座に同期。
- **REBORN**: 転生コマンドを送信し、次世代キメラを誕生させる。
- **SNAPSHOT**: 現在の観測ステーションのスクリーンショットを高解像度 PNG で保存。
- **BENCH**: CPU 描画ベンチマークを実行。

### 6. シリアル自動接続 & オフラインプレビュー
- 実機が PC に接続されると、COM ポート（COM24 等）を自動検出して即座にオンライン同期します。
- 実機が接続されていない時でも「OFFLINE SIMULATOR」として動作し、3D キメラを自由に愛でることができます。
